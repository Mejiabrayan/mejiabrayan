# Brayan Mejia Cuenca

Design-minded web developer building useful, polished web experiences since 2019.

I enjoy taking an idea from interface concept to a working product, especially interactive tools, maps, and full-stack apps. I use AI as part of my workflow to move through unfamiliar problems faster while keeping the craft and decisions in my hands.

## Selected work

- [Brayancodes.com](https://brayancodes.com) — My personal site and portfolio, built with Astro, TypeScript, Tailwind CSS, and Turso.
- [Rapid BART Tracker](https://github.com/Mejiabrayan/Rapid-Bart-Tracker) — A real-time Bay Area transit tracker with station departures, service alerts, and an interactive map.
- [Virtual Gallery](https://github.com/Mejiabrayan/virtual-gallery) — A 3D gallery for uploading and displaying artwork, built with Next.js, Three.js, and Supabase.
- [myMovies](https://github.com/Mejiabrayan/MyMovie-App) — A movie discovery app connected to a REST API, with account and favorites features.
- [myMovies REST API](https://github.com/Mejiabrayan/MOVIES-REST-API) — A Node.js and Express API backed by MongoDB.
- [Chatty](https://github.com/Mejiabrayan/Chatty-app) — A React Native chat app with messaging, image sharing, and location sharing.
